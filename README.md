# سام ميكروتك (SamMikrotik)
**نظام مالي ومحاسبي وإداري متكامل لشبكات الإنترنت وموزعي الميكروتك وفق معايير المحاسبة الدولية (IFRS)**

---

## 🌟 نظرة عامة (Overview)
**سام ميكروتك** هو تطبيق أندرويد متقدم للمحاسبة وإدارة شبكات الإنترنت اللاسلكية لمزودي الخدمات وموزعي الميكروتك وأبراج الاتصالات، مبني وفق مبدأ العمل دون اتصال بالإنترنت أولاً (**Offline-First**). يحتوي التطبيق على دفتر أستاذ عام مزدوج القيد متوازن بنسبة 100% مع ضمان عدم التعديل أو الحذف المباشر للقيود بعد ترحيلها، إضافة إلى أدوات فحص طيف الواي فاي الميداني، والنسخ الاحتياطي السحابي المشفر والمقطّع، ومساعد الذكاء الاصطناعي المستقل بمفاتيح المستخدم الخاصة.

---

## 🛠️ البنية التقنية والمميزات الحقيقية (Core Features)

1. **دفتر أستاذ عام ذو قيد مزدوج صارم (Strict Double-Entry General Ledger):**
   - توافق دقيق مع معايير التقارير المالية الدولية (IFRS).
   - حماية قواعد البيانات على مستوى محرك SQLite Triggers لمنع تعديل أو حذف أي قيد مالي مرحل نهائياً.
   - إلغاء وتعديل المعاملات حصرياً عبر قيود عكسية موثقة (Reversal Entries).
   - حسابات مالية خالية من الكسور العائمة: استخدام وحدات الصغرى الصحيحة (`Long minor units`) دون استخدام `Double` أو `Float`.

2. **معاملات وفواتير وسندات مالية متكاملة:**
   - فواتير مشتريات ومبيعات وسندات صرف وقبض مع التحقق الصارم من القيم الموجبة لمنع الفواتير الصفرية أو السالبة.
   - مساهمات رأس المال النقدية والعينية وحساب الإهلاك للأصول الثابتة.
   - كشوفات الحسابات وميزان المراجعة وقائمة الدخل وقائمة التدفقات النقدية والمركز المالي.

3. **محلل طيف الواي فاي الميداني (WiFi Spectrum Analyzer):**
   - قراءة حية ومباشرة من بطاقة شبكة الجهاز عبر `WifiManager` دون أي بيانات وهمية أو محاكاة برمجية.
   - فحص ترددات 2.4 جيجاهرتز و 5 جيجاهرتز واقتراح أفضل القنوات تجنباً للتداخل.

4. **نسخ احتياطي سحابي مقطّع ومشفر (Chunked & Encrypted Cloud Backup):**
   - معمارية نسخ مقطّع لمعالجة قواعد البيانات الكبيرة وتجاوز سقف حجم وثائق Firestore (≤ 400KB لكل جزء).
   - تشفير متماثل قوي من جانب العميل باستخدام خوارزمية **AES-256-GCM** مع مفتاح مشتق من عبارة مرور المستخدم عبر دالة **PBKDF2WithHmacSHA256** (210,000 تكرار و 16-byte salt).
   - توليد IV فريد 12-byte لكل جزء على حدة مع فحص تجزئة SHA-256 للتحقق من سلامة البيانات.
   - حفظ بيان النسخة (Manifest) في وثيقة مستقلة واستعادة ذرية (Atomic Restore) مع إنشاء لقطة أمان محلية (Local Safety Snapshot) وتدقيق شامل للقيود قبل اعتماد الاستعادة.
   - مسار استعادة متوافق مع النسخ القديمة لضمان عدم فقدان أي بيانات سابقة.

5. **مساعد الذكاء الاصطناعي (AI Assistant):**
   - نموذج إدخال مفتاح API الخاص بالمستخدم (BYOK) لدعم نماذج Google Gemini و OpenAI و DeepSeek.
   - لا يتم إرسال أي بيانات محاسبية في الخلفية؛ يُرسل نص الاستفسار الصريح فقط عند طلب المستخدم.

6. **أمان وخصوصية تامة بدون أذونات حساسة:**
   - تم التخلص بالكامل من إذن جهات الاتصال `READ_CONTACTS`. يتم اختيار العملاء والموردين عبر منتقي جهات الاتصال الرسمي للنظام (`Intent.ACTION_PICK`) بصلاحية قراءة مؤقتة للرقم المختار فقط.
   - خلو كامل من أي حزم إعلانية (No Ads SDK) أو أدوات تتبع وتحليلات طرف ثالث (Zero Analytics).

## 📋 المتطلبات والمتغيرات (Prerequisites & Requirements)

- **بيئة التطوير ونظام التشغيل:** Android Studio Ladybug / Koala أو بيئة Linux/macOS/Windows مع JDK 17 أو JDK 21.
- **Android SDK:**
  - `compileSdk`: 34
  - `targetSdk`: 34
  - `minSdk`: 26 (Android 8.0 Oreo فما فوق)
- **محرك البناء:** Gradle 8.x + Kotlin 2.0.x + Android Gradle Plugin 8.7.x.

## 🔒 الملفات الموردة من المالك (Owner-Supplied Files & Credentials)

الأرشيف المصدري لا يحتوي على الملفات السرية وحزم التوقيع لأسباب تتعلق بأمان سلسلة التوريد (Supply Chain Security). يجب على المالك توفير الملفات التالية محلياً:

1. **حزمة Gradle Wrapper (`gradle-wrapper.jar`):**
   - الملف غير مضمن في المستودع منعاً لإيداع ملفات ثنائية غير مدققة.
   - يمكن تشغيل البناء مباشرة عبر أمر `gradle` المثبت على النظام، أو إعادة توليد الـ wrapper محلياً عبر تشغيل `gradle wrapper`.
2. **ملف إعدادات Firebase (`google-services.json`):**
   - يوضع في مسار: `app/google-services.json` (يتم تنزيله من وحدة تحكم Firebase Console الخاصة بالمشروع).
3. **مفتاح التوقيع لإصدار الإنتاج (Keystore):**
   - مفاتيح `release.keystore` الخاصة بنشر التطبيق على Google Play يتم تحديد مسارها ومتغيراتها عبر متغيرات البيئة أو إعدادات البناء الخاصة بالمالك.
4. **ملف الإعدادات المحلية (`local.properties`):**
   - يتم إنشاؤه في المجلد الجذري للمشروع لتحديد مسار حزمة تطوير أندرويد (Android SDK):
     ```properties
     sdk.dir=/Users/username/Library/Android/sdk
     # أو على نظام Linux:
     # sdk.dir=/home/username/Android/Sdk
     ```

## ⚙️ أوامر البناء والاختبار (Build & Test Commands)

> **ملاحظة:** يتم استخدام أمر `gradle` المثبت محلياً مباشرة:

### 1. تشغيل حزمة اختبارات الوحدة واختبارات Robolectric:
```bash
gradle :app:testDebugUnitTest --console=plain
```
*تتضمن الحزمة أكثر من 220 اختباراً تغطي توازن الدفاتر المحاسبية، وتشفير واستعادة النسخ الاحتياطية، وأمان واجهات برمجة التطبيقات.*

### 2. بناء نسخة الفحص والتطوير (Debug APK):
```bash
gradle :app:assembleDebug
```
*يتم إنتاج ملف الـ APK في المسار: `app/build/outputs/apk/debug/app-debug.apk`.*

### 3. بناء حزمة نشر الإنتاج (Release Bundle):
```bash
gradle :app:bundleRelease
```
