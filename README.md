# سام ميكروتك (SamMikrotik)
**نظام مالي ومحاسبي وإداري متكامل لشبكات الإنترنت وموزعي الميكروتك وفق معايير المحاسبة الدولية (IFRS)**

---

## 🌟 نظرة عامة
**سام ميكروتك** هو تطبيق أندرويد محاسبي وإداري موجه لأصحاب وشبكات الإنترنت وموزعي الميكروتك وأبراج الاتصالات، يعمل دون اتصال بالإنترنت أولاً (Offline-First) مع دفتر أستاذ مزدوج القيد 100% متوازن، مدعوماً بميزات فحص طيف وترددات الواي فاي اللاسلكية والنسخ الاحتياطي السحابي المشفر.

---

## 🛠️ المميزات الرئيسية
1. **دفتر أستاذ عام ذو قيد مزدوج (Double-Entry General Ledger):**
   - توافق كامل مع معايير التقارير المالية الدولية (IFRS).
   - لا يمكن تعديل أو حذف القيود بعد الترحيل، ويتم التعديل أو الإلغاء عبر قيود عكسية موثقة.
2. **سندات الصرف والقبض وفواتير المبيعات والمشتريات:**
   - دعم التعدد المالي والتسعير بأسعار صرف متعددة، مع دعم أطراف التعامل (عملاء، موردين، شركاء).
   - مساهمات رأس المال النقدية والعينية متعددة الأصول الثابتة.
3. **محلل طيف الواي فاي الميداني (WiFi Spectrum Analyzer):**
   - فحص ترددات 2.4GHz و 5GHz واقتراح أفضل القنوات تجنباً للتداخل والتشويش.
4. **نسخ احتياطي سحابي مقطّع وآمن (Chunked Cloud Backup):**
   - تقسيم النسخ الاحتياطية إلى أجزاء صغيرة (≤ 500KB) مضغوطة بـ GZIP ومطابقة لحدود Firestore.
   - دعم التشفير بعبارة مرور المستخدم (AES-256-GCM + PBKDF2).
   - حماية الاستعادة بلقطات أمان محلية وفحص توازن القيود المحاسبية.
5. **جاهزية كاملة لمتجر Google Play:**
   - زيرو أذونات حساسة (Zero-Permission Contact Picker).
   - ضغط وتصغير آمن R8 و Proguard.
