# لوحة إدارة وتفعيل اشتراكات SamMikrotik (Admin Control Panel)

تتيح هذه اللوحة لمدير نظام تطبيق **SamMikrotik** إدارة التراخيص وإصدار مفاتيح التفعيل الرقمية المشفرة لمشتركي النسخة الاحترافية (PRO)، سواءً عبر التفعيل غير المتصل (Offline License Keys) أو عبر المزامنة السحابية (Firebase Cloud Sync).

---

## 🚀 محتويات المجلد

1. **`index.html`**:
   - لوحة تحكم تفاعلية متكاملة تعمل مباشرة في المتصفح دون الحاجة لأي خادم أو تثبيت حزم.
   - مزودة بمحرك تشفير متقدم يعتمد على معيار **RSA-2048 (SHA256withRSA)** للتوقيع الرقمي باستخدام Web Crypto API.
   - تتيح توليد مفاتيح الترخيص، نسخ رسائل التفعيل المجهزة للواتساب، فحص واختبار المفاتيح، والاحتفاظ بسجل العملاء والتراخيص محلياً في المتصفح.

2. **`generate_license.js`**:
   - أداة سطر الأوامر (CLI) المبنية بواسطة Node.js لتوليد المفاتيح آلياً عبر السيرفر أو التيرمنال.

---

## 🔑 كيفية استخدام لوحة التحكم في المتصفح (`index.html`)

1. قم بفتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome / Firefox / Edge / Safari).
2. **لإصدار مفتاح جديد لعميل:**
   - اطلب من العميل الدخول إلى شاشة **"إدارة الاشتراك والتفعيل"** في تطبيق SamMikrotik على هاتفه، والضغط على زر **"نسخ"** بجانب **بصمة الجهاز (Hardware ID)** (مثال: `SAM-A1B2-C3D4-E5F6`).
   - في لوحة التحكم، الصق معرف الجهاز في حقل `Hardware Device ID`.
   - أدخل اسم العميل أو اسم الشبكة.
   - اختر مدة الصلاحية: (شهر، 6 أشهر، سنة، أو دائم مدى الحياة Lifetime).
   - اضغط على **"توقيع وتوليد مفتاح التفعيل الرقمي"**.
   - اضغط على **"نسخ رسالة واتساب للعميل"** وأرسلها للعميل مباشرة.

---

## 💻 استخدام أداة السطر البرمجي (`generate_license.js`)

يمكن استخدام أداة Node.js لتوليد المفاتيح من سطر الأوامر:

```bash
# الصيغة:
node admin-panel/generate_license.js <hardwareDeviceId> [durationMonths] [customerName]

# أمثلة:
# 1. مفتاح لمدة سنة (12 شهراً):
node admin-panel/generate_license.js SAM-A1B2-C3D4 12 "شبكة النور"

# 2. مفتاح دائم مدى الحياة (0 شهور):
node admin-panel/generate_license.js SAM-A1B2-C3D4 0 "مؤسسة الأفق"

# 3. مفتاح شامل يعمل على أي جهاز (*):
node admin-panel/generate_license.js "*" 1 "مفتاح تجريبي شامل"
```

## ☁️ إدارة التفعيل عبر السحابة (Firebase Firestore)

إذا كان العميل قد سجل دخوله عبر حساب Google في التطبيق، يمكنك تفعيل اشتراكه سحابياً دون الحاجة لإرسال مفتاح يدوي:

1. افتح مشروع Firebase الخاص بك.
2. انتقل إلى **Cloud Firestore** ثم إلى المجموعة:
   ```text
   users/{uid}/subscription/status
   ```
3. أضف أو عدّل الحقول التالية:
   ```json
   {
     "tier": "PRO",
     "expirationEpochMs": 1789900000000,
     "customerName": "اسم العميل",
     "updatedAt": 1730000000000
   }
   ```
4. في التطبيق، يضغط العميل على **"مزامنة والتحقق من الاشتراك عبر السحاب"** ليتم تحويل حسابه فوراً إلى النسخة الاحترافية (PRO).
